Handbook Entry

schema2object is a JavaScript runtime that binds JSON Schema Draft-07 to live runtime objects.

Current repository posture: JavaScript is the only active runtime implementation. Python, Rust, and TypeScript chapters are projection/reference notes for carrying the same schema truth into other ecosystems.

The legal entry posture is: schema file first, root loader second, resolved schema node third, then validate() or ObjectTree.from() at the boundary.

Reader Contract

Use this handbook as a routing system. Usage is a standalone chapter; runtime docs describe the API surface; Draft-07 docs define schema legality; language docs are projection guidance only; proof requires fresh gates.

Forbidden Drift

  • Do not reintroduce active python/, rust/, TypeScript package code, references/, or js/lab/.
  • Do not make examples with inline schema objects as the primary posture.
  • Do not use new ObjectTree() as the external validation boundary.
  • Do not scatter durable documentation outside docs/handbook/.
